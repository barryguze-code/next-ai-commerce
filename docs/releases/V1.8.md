# Version 1.8 — Preparing clearer Amazon fee reviews

This release installs the foundation for a controlled Amazon fee review rollout. Fee collection and fee acceptance remain disabled until separately enabled. An initial read-only rollout can show unavailable evidence without implying that missing costs are zero.

When enabled with verified evidence, Orders and Marketplace SKUs can distinguish fulfillment and referral charge differences, retain earlier fee evidence, and present a separate confirmation for prospective fees. Accepted amounts apply only to the matching SKU basis for future estimates; historical orders and differences remain available.

This release does not seed production examples, import local data, activate Amazon collection, change product mappings, or rewrite stored inventory quantities. The initial production UAT mode is an operational decision recorded separately.
