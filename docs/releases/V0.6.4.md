# Version 0.6.4 — Fast operational Orders

Released: 2026-08-31

## Performance

- Removes request-time inventory reconciliation from the Orders page; the existing background worker
  remains responsible for mapping, reservation, and readiness changes.
- Replaces up to 250 per-order item queries with one batch item query for the visible page.
- Adds server-side pagination at 25 orders per page.
- Adds supporting indexes for order-item batches and reservation status lookups.
- Keeps the quiet refresh behavior, now with a fixed query count rather than an N+1 query pattern.

## Order experience

- Removes date-group separators and keeps a straightforward newest-first queue.
- Uses the first available SKU image as the order visual and images on every item row.
- Shows Amazon's own order status separately from Next AI Commerce inventory readiness.
- Opens item rows by default with readable typography and no order-level product description.
- Adds a Seller Central icon linking directly to the selected Amazon order.
- Shows ordered quantity, mapped available inventory, and mapping action for each item.
- Adds Today’s orders, Today’s sales, and 30-day sales summaries.
- Reserves visible space for Profit, Margin, and Markup without presenting incomplete calculations.
- Keeps Buy Shipping visible but safely inactive until label purchasing is implemented.

## Data rules

- Cancelled orders are excluded from sales totals.
- Historical orders remain reporting-only and cannot reserve or deduct inventory.
- Available quantity is derived from the mapped catalogue components, inventory ledger, and active
  order reservations; bundle availability follows the limiting component.
