# Next AI Commerce 0.3.0

Release date: 2026-08-26

Version 0.3 establishes the live Amazon US data foundation: resumable initial preparation,
normalized marketplace persistence, and recurring background synchronization after activation.

## Included

- Tenant/store-scoped Amazon SP-API orchestration with database leases and resumable report polling
- Essential-data readiness gate so users can work before historical enrichment finishes
- Persistent source reports plus normalized listings, orders/items, inventory, ledger movements,
  customer shipments, returns, finances, reimbursements, and fee estimates
- Marketplace-local date handling and UTC instants aligned with Seller Central display behavior
- Versioned Inventory Ledger reconciliation that supports corrected and identical Amazon rows
- Recurring Amazon schedules for order changes, current inventory, listings, returns, finances,
  reimbursements, fees, shipment history, and wider safety reconciliations
- Overlapping data windows and idempotent upserts to catch cancellations and late Amazon changes
- Persistent schedule health and high-watermark visibility for operational support
- Cadence-aware schedule bootstrap that avoids duplicate daily reports immediately after initialization
- Immediate warning/skip behavior for optional reports Amazon marks unavailable
- Safe marketplace disconnect that revokes credentials while retaining imported business history
- Platform-wide background-processing notice after core data becomes usable

## Schedule summary

- Orders: 15-minute 24-hour overlap, 6-hour 7-day reconciliation, daily 30-day reconciliation
- Current FBA inventory: hourly
- Returns and finances: every 4 hours with 7-day overlap
- Listings, Inventory Ledger, reimbursements, FBA fees, and customer shipments: daily
- FBA customer shipments remain the final/lowest-priority historical report

The detailed operational contract is in
[`MARKETPLACE_SYNC_OPERATIONS.md`](../MARKETPLACE_SYNC_OPERATIONS.md).

## Intentionally deferred

- Walmart business-data workers and normalizers (architecture documented; connection/auth remains)
- Amazon notification subscriptions for lower-latency event delivery
- Advertising API, which is a separate authorization/API surface from SP-API
- Schedule administration UI and alert delivery
- Catalog/vendor upload and marketplace SKU-to-product mapping

## Verification and rollback

The complete automated suite passed with 32 tests and zero failures.

Database migrations are forward-only through `V19`. Application rollback uses the preserved
v0.2 Git tag/code plus a database backup taken before applying v0.3 migrations. Never delete or
rewrite an applied Flyway migration.
