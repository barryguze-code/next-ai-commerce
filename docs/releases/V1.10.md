# 1.10 — Shopify orders and shared warehouse operations

Status: release candidate in verification; not deployed or activated.

Shopify products and orders use the account catalogue, shared mapping controls,
packing workflow and inventory ledger. Marketplace units retain their mapped pack
quantities. The shared ledger shows stock, reservations, movements and related
marketplace SKUs, with uncertain relocations held for review.

Inventory publication uses explicitly approved source locations and the verified
Shopify destination. New warehouse locations are not included automatically.
Unknown submission outcomes are checked before another write, and an unexplained
remote stock decrease requires order reconciliation. Local marketplace writes and
new Shopify publication remain disabled by default.

Shopify cost estimates use mapped product costs, supported planning shipping and
Other cost per sold SKU unit. Missing shipping or cost evidence remains unknown;
payment fees, taxes and refunds are not represented as settled profit.

This release adds V116–V124 on the audited production V115 baseline. Exact CI,
independent inventory review, recovery verification and destination/permission
preflight remain required before activation. Production data cleanup is separate;
no local test data or automatic catalogue merge is included. Retain the previous
artifact and configuration; database restoration is never an automatic rollback.
