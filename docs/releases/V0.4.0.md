# Next AI Commerce v0.4.0 — Catalogue foundation

## Included

- Super Admin-only Global Catalogue navigation and page.
- Tenant-isolated Account Catalogue for all account roles.
- Global product matching by UPC/EAN/GTIN/MPN; unmatched account products create a global draft safely.
- Account SKU and expiration-handling setup.
- Tenant vendor records with currency and a zero-default discount.
- Effective-dated vendor offers and immutable cost history.
- Multi-document receiving-session model with shared freight, duty/import, and other cost amounts.
- Value, quantity, weight, or manual shared-cost allocation foundation.
- Guided CSV/TSV/XLSX upload, automatic column suggestions, preview, validation, and explicit approval.
- Marketplace SKU mapping model, including multipack quantities.
- Immutable inventory-ledger foundation for FIFO/FEFO receiving.

## Next implementation slice

- Invoice and packing-list receiving with one-time versus default-cost decisions.
- FEFO/FIFO inventory allocation UI and receiving corrections.
