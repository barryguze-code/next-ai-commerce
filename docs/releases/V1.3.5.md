# v1.3.5 — Receiving defaults and shelf-life responsiveness

- Receiving exception entries start at zero. Clearing resets both case inputs; prior receipts make Sellable start at zero. Totals remain calculated and saving requires positive quantities.
- Global shelf-life save confirms the number of mapped SKUs to review. Automatic plans use current rules; intentional product/SKU overrides remain intact.
- A dedicated transactional sale outbox follows stock/reservation/policy/mapping changes without competing with quantity publishing. Managed discounts receive priority; Amazon confirmation is asynchronous, not a guaranteed same-minute storefront change.
- Source-reported unshipped invoice rows are informational only and are retained on new imports. Old discarded source rows cannot be reconstructed without the original invoice.
- Local cannot publish Amazon prices. Existing production account/connection restrictions remain unchanged.
