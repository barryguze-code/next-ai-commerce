# Next AI Commerce v0.5.8 - Store-scoped Marketplace SKUs

## Amazon assortment workspace

- Marketplace SKUs is now a real operational page under Catalogue & Purchasing.
- The selected store controls every result, preventing listings from different accounts or connections from mixing.
- Account overview asks the user to choose a store; Walmart selection explains that its catalogue sync is not available yet.
- Store switching keeps the user on Marketplace SKUs and reloads the chosen store.

## Operational visibility

- Overview cards show total listings, active in-stock listings, out-of-stock listings, unmapped listings, and available units.
- Each row combines Amazon title/image, ASIN, Seller SKU, listing state, price, fulfillment, current availability,
  inbound/reserved/unfulfillable quantities, 30-day units and revenue, the latest fee estimate, and account-catalogue mapping.
- Direct, marketplace-aware shortcuts open the SKU in Seller Central or its Amazon product detail page in a new tab.
- Missing images, prices, fees, ASINs, and mappings have calm, readable fallback states.

## Scale and usability

- Search by Seller SKU, ASIN, or title and filter by Active, Out of stock, Inactive, or Unmapped.
- Filtering, summary counts, and 100-row pagination run server-side for large catalogues.
- Desktop keeps a deliberately information-rich table; mobile transforms every listing into a readable two-column card.
- Light and dark appearances use the same status language, contrast, and interaction hierarchy.

## Security and data ownership

- Viewer, Operator, Administrator, Owner, and Platform Administrator roles can read the page.
- Existing tenant row-level security remains active, and every query includes both tenant and marketplace connection.
- No credentials or raw source documents are exposed to the browser.
- This release adds no database migration; it presents normalized Amazon data already persisted by synchronization.
