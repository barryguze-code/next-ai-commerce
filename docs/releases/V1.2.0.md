# v1.2.0 — Inventory that follows your warehouse

User-approved release, prepared for production deployment. Deployment completion is verified separately.

## Shelf counts and open orders

- Physical-count uploads accept AppSheet-style expiration dates such as 5/16/27 (May 16, 2027). Two-digit years mean 2000–2099; impossible calendar dates are rejected.
- Physical counts represent stock on the shelves, excluding packed orders waiting for pickup.
- Applying a count recalculates open-order reservations. A lower count can reveal a real shortage without being rejected because of the previous reservation total.
- Packed and shipped orders no longer appear in the actionable Stock shortage or Unmapped tabs.
- Marking an order packed removes its recorded reserved units from shelf stock once. Repeated order syncs do not deduct them again. This still does not update Seller Central.
- A shipped/packed order with mapped items but missing inventory records gets a zero-quantity Inventory Ledger explanation, including the order, SKU and missing each quantity. Historical shipments do not consume newly counted stock.
- Undoing a local packing mark returns recorded packed units to the shelf and recalculates reservations. Only use Undo when the goods are physically returned to the shelf. Missing historical inventory is not manufactured.
- Unchanged counts are recorded as observations, so a zero adjustment still provides a count record.

## Easier inventory setup

- Display dates use MM/DD/YY, retaining time and timezone where applicable. Import/API dates remain unchanged and native date pickers follow browser locale.
- Correct an expiration date beside the Available Inventory date. The full shelf position moves to the corrected date with paired ledger entries and refreshed open-order reservations. Matching item/location/date positions combine; no separate lot identity is implied. Existing sale/hold/removal plans must be cleared first, and stale quantity edits are rejected.
- Missing-stock shipment entries show a colored Shipped label, a Without stock record subtitle, and a concise linked order reference. Original audit notes remain stored.
- Right-click a product picture in Available Inventory or Account Catalogue to sync Amazon's main image into both Account and Global Catalogue. Uses an active SKU mapped only to that item, avoiding mixed-product bundle pictures; failures keep existing images.
- Order shortage and mapping action menus open above the table so short result lists no longer crop their actions.
- Physical count opens a menu with Upload Physical Count first, the latest three files, and Uploaded Files for the full list.
- Add vendors and locations directly from Available Inventory using the same dialogs as Account Catalogue.
- Edit or delete unused locations from the shared location manager. MAIN and locations linked to catalogue assignments, stock history, receipts, reservations, shipments or pending physical-count uploads are protected, with a detailed explanation when a change is blocked. No stock or historical records are silently removed.
- Catalogue and inventory controls share consistent button styling.
- Add Product uses the familiar Item Code terminology.

## Count scope

Only explicitly counted batches change by default. The replace-products option also zeros omitted batches of included products. Products absent from the file are not wiped.

## Local acceptance checks

Confirm count scope and quantities in the review before applying. Test a mapped order through reservation, packing, repeated sync, and undo. Check a historical shipped shortage has a zero ledger explanation and does not reduce stock. Check partial/unknown/unmapped fulfillment edge cases separately before production approval.
