# Version 0.6.6 — Inventory cost and movement clarity

## Available inventory

- Each inventory position opens a focused audit trail showing receipt, order depletion, correction, and adjustment movements.
- Position context includes initially received, on hand, reserved, available, first-received, and last-movement values.
- Unit costs display as currency with two decimal places throughout Available Inventory and Inventory Ledger.
- The expiration action control is aligned and isolated from the row-level history interaction.

## Receiving cost accuracy

- Invoice merchandise cost remains the cost source for the receipt.
- Existing catalogue default cost is preserved; a visible warning appears when the invoice cost differs.
- New catalogue products still use their first invoice cost as the initial vendor default.
- Deposit and other invoice-line fees can be entered per each and remain separately auditable while contributing to landed unit cost.
- Shared freight, duty/import amount, and receiving-level other costs continue to be allocated when the receiving is posted.

## Database

- Migration `V33__receiving_item_fees.sql` adds separate non-negative per-unit deposit and other-fee components to purchase-order items and inventory ledger entries.
