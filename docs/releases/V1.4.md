# v1.4.0 — Workspace consistency and collaboration

This release brings the locally reviewed workspace changes into production: shared table and dialog styling, improved caching, inventory plan handling, store-wide tasks with optional deadlines, product visuals in collaboration, and compact floating chat controls.

The final polish shortens aggregate inventory captions, uses the supplied collaboration-task artwork, removes the deadline field above the new-conversation composer, and automatically inserts separators while typing dates.

Existing publication permissions remain unchanged. Database migrations are additive; deployment uses the CI-tested artifact, checksum verification, a pre-release database backup, and application rollback safeguards.
