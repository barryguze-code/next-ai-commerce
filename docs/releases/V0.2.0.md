# Next AI Commerce 0.2.0

Released: 2026-08-25

Version 0.2 is the preserved rollback reference for the account/store operating model and reusable
UX foundation. Its original release notes remain in the root `RELEASE_NOTES.md`; this standalone
document exists so later releases never overwrite the v0.2 record.

## Included

- Account-wide All stores context and required store context for operational modules
- Searchable account/store switcher with marketplace identity and flags
- Role-aware grouped navigation, light/dark appearance, responsive Apple-system typography
- Streamlined invitations, verified activation, and tenant/store access boundaries
- Initial information architecture for sales, catalog, inventory, recovery, integration, and administration

## Rollback point

The Git tag `v0.2.0` is the code rollback point. Restore the matching pre-v0.3 database backup when
rolling back across later Flyway schema changes.
