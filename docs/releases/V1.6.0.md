# v1.6.0 — Replenishment planning and estimated profit

Replenishment is now presented without a Draft badge. Suggested quantities,
account case-size overrides, stock-status colours, product-specific basket
feedback and compact basket rows support purchasing review. Whole cases show
as integers; fractional cases show two decimals and each quantities stay whole.
Basket totals use current USD catalogue costs and identify missing costs.
Baskets remain page-only plans, not saved purchase orders or vendor submissions.

Estimated FBM profit is available in Orders, Marketplace SKUs, related listings
and Replenishment. Costs include mapped product units, $1 other cost per sold
SKU, tiered referral fees and effective-dated packaging defaults. Missing costs
remain pending. Estimates are not historical accounting results. FBA profit is
not included. Amazon price publishing stays separately gated and requires an
explicit confirmation; deployment does not enable publishing.

## Release operations

- Additive Flyway migrations V91–V95 add SKU other costs, shipping-rate history,
  order packages, account case-size overrides, price confirmation audit and a
  packing-history index. Existing SKUs receive the requested $1 default.
- No local database, catalogue or packing-history files are imported by this
  release. Production uses its existing business data.
- Existing production workflow validates tests, the exact artifact checksum,
  server disk space and a full server-local database backup before restart.
- Application rollback restores the prior JAR and runtime configuration;
  additive database changes remain. A verified database backup is retained.
- Verify deployed version/revision, migrations through V95, login and
  replenishment/profit pages after deployment. Preserve existing mail and
  Amazon write policies.
