# Version 0.6.11 - Shared operational table widget

- Marketplace SKUs, Available Inventory, and Orders now use the same table-widget presentation and column controls.
- Every current column is visible by default; newly available Amazon fields start hidden.
- The column panel uses open and closed eye states, searchable end-user labels, reset, and column-order controls.
- Visibility and order are retained for one year in a small browser cookie scoped to each table.
- Marketplace SKU price now shows recent per-unit customer shipping for FBM listings when synchronized order lines contain shipping revenue.
- Optional marketplace columns include customer shipping, shipping template, condition, FNSKU, inbound, reserved, and unfulfillable quantities.
- The order stream keeps product images and Seller Central links, adds a shared column header, and keeps a continuous status rail around multi-product orders.
- Live order refresh reapplies the user's table settings after new Amazon orders arrive.

## Preference storage

Browser storage is appropriate for the current UAT because it is fast, account-safe, and requires no profile writes. Preferences do not follow the user to another browser and are lost when site data is cleared. The widget uses a versioned preference shape so a later user-profile persistence service can replace the cookie without changing the UI.
