# Version 0.6.13 - Consistent order rows and sales totals

- Every order item now uses the same columns, including repeated Amazon order ID, purchase time, status, and Seller Central shortcut for multi-item orders.
- Removes the special multi-order header so column visibility and ordering behave identically for every row.
- Alternates subtle NextAI blue and green order-group backgrounds; the left group rail uses the matching hue.
- Keeps all items from one Amazon order inside the same tint and rail, with fine dividers between products.
- Backfills order totals from synchronized item price, item tax, customer shipping, shipping tax, and promotions.
- Future Amazon order imports recalculate the order total as each line is normalized.
- Today’s Sales and order-level sales now use the populated order total.
- The Orders toolbar displays the latest completed Amazon connection sync time so data freshness is visible.
- Recurring Amazon order synchronization remains enabled by default on a 15-minute profile.
