# 1.14 — Package rates and consistent inventory workspaces

## Packages and planning costs

- Manage packages from Orders and Marketplace SKUs, rename or merge them, and maintain separate effective-dated planning rates with history.
- Print the selected package and storage location on packing slips.

## Catalogue and purchase plans

- Remove unused catalogue products safely, with inactive or archive alternatives when records have dependencies.
- Add Account Catalogue products to purchase plans with case quantities, searchable selection and editable draft names.

## Consistent workspace controls

- Use consistent optimized icons, table actions and anchored table tools across operational pages.
- Review mapped inventory movements and warehouse availability by location before confirming FBA stock deductions. Missing shipment evidence remains protected.
