# v1.3.0 — release candidate

## User-facing changes

- Consistent operational table, picture-editing, mapping, collaboration and action controls.
- Account-scoped tagged smart filters, dynamic dates and compact filtered totals.
- Shared catalogue-item inventory fan-out to mapped FBM SKUs, multipacks and bundles.
- Durable publication queue, priority zero updates, verification/retries and a sync status page.
- Individual unresolved-order checks without a purchase-age cutoff. A missing order is not
  a cancellation. Overdue/missing checks retain reservations and expose review warnings.
- Confirmed cancellation releases are logged without adding physical stock. Stale responses
  cannot overwrite a newer cancellation. Packed stock is not automatically returned.
- Partial shipments post only newly shipped components and keep the remainder reserved.
  Missing prior shipment allocations hold all related SKUs at zero with a ledger explanation;
  counting every remaining location/expiration batch releases the hold without retrospective deductions.

## Migration and release status

Migrations 74–78 add smart filters, shared picture overrides, the inventory publication outbox,
unresolved-order status checks and partial-shipment reviews. No local business data or credentials
are copied to production.

shipments, packs/bundles, partial cancellation, missing stock history and complete versus
incomplete physical counts. Direct status checks cannot release reservations if Amazon's
shipped-item total differs from the imported item details; those checks retry for review.
