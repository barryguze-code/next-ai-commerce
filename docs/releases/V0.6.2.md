# Version 0.6.2 — Safe fulfillment migration

Released: 2026-08-30

## Correction

- Repairs startup failure in `V31__live_order_fulfillment.sql` for databases containing existing
  marketplace connections.
- Temporarily disables forced row-level filtering only while Flyway backfills the new
  `inventory_activated_at` boundary across legacy rows.
- Re-enables and forces tenant row-level security before applying the `NOT NULL` constraint.
- Preserves all connections, credentials, synchronized records, and inventory data.
- Keeps existing imported orders historical and uses the migration time as the live-order boundary.

The migration is transactional: the earlier failed attempt was rolled back by PostgreSQL and is safe
to retry when the application starts.
