# Next AI Commerce v0.5.1 - Resilient multi-document intake

## Included

- Upload one or several invoices or packing lists into one receiving workspace.
- Add later document batches, including documents for another vendor, to the same receiving.
- Atomic batch behavior prevents half-created receiving plans when one selected file fails.
- Required vendor validation with friendly missing, invalid, inactive, and cross-account messages.
- Per-file names in parsing errors so the user knows exactly which document needs attention.
- Explicit 20 MB per-file and 80 MB per-batch limits with safe oversized-upload handling.
- A polished Next AI Commerce fallback page replaces Spring's Whitelabel error page.
- Binding, multipart, missing-field, malformed-number, unsupported-file, duplicate-document, and unexpected persistence failures are logged and returned as non-technical guidance.

## Verification

- Full automated suite: 43 tests passed, 0 failures, 1 optional real-PDF diagnostic skipped by default.
- Dedicated tests cover missing-vendor rejection and two invoices entering one receiving batch.
