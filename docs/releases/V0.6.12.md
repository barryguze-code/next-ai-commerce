# Version 0.6.12 - Flat order table presentation

- Removes the remaining legacy rounded order cards, margins, shadows, and separated row backgrounds.
- Orders now use the same flat, full-width table surface, header density, borders, and color-coded left rail as Available Inventory.
- Single-item orders occupy one aligned table row.
- Multi-product orders use one compact order reference followed by contiguous product rows inside a single status rail.
- Multi-order headers retain the Amazon order ID, Seller Central shortcut, and a compact product/unit count without duplicating finance placeholders.
