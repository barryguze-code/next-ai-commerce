# Version 0.6.10 - Finite Amazon image enrichment

- Successful Amazon main-image lookups are persisted as `AVAILABLE` and are never submitted to the catalogue API again.
- Amazon `NOT_FOUND` responses mark the listing `Removed by Amazon` and permanently stop image polling for that listing.
- A listing that reappears in a later Amazon listing report automatically returns to the visible catalogue and becomes eligible for one fresh image lookup.
- Temporary Amazon or network failures use progressive backoff: one hour, six hours, one day, then seven days.
- Empty but successful image responses are recorded as `NO_IMAGE` rather than retried forever.
- Image source, status, attempts, next attempt, and sanitized failure details are retained for support and for a future object-storage/CDN mirror.
- The marketplace SKU table exposes removed listings in the existing removed/deleted history filter.

## Media-storage boundary

No AWS object-storage bucket or CloudFront distribution is configured in this repository. Version 0.6.10 therefore retains the resolved Amazon CDN URL and never repeats the SP-API catalogue request. The new source URL and lifecycle columns provide the durable handoff point for a future S3/CloudFront mirroring adapter without changing catalogue consumers.
