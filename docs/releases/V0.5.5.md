# Next AI Commerce v0.5.5 - Expiration-batch receiving

## Warehouse readability

- Expected, received, remaining, cases, units per case, loose eaches, and available inventory render as whole units without database-scale decimals.
- Progress uses larger `EXP`, `REC`, and `REM` labels with accessible tooltips.
- Removed the redundant text status below progress; row color and the table legend remain the source of status identity.
- Increased compact-table typography while preserving one product per row.

## Multiple expiration dates

- Every Receive action represents one physical expiration batch.
- The row shows `Batch 1`, `Batch 2`, and so on using its saved receipt count.
- After a partial expiration batch is saved, the same product row remains open, recalculates the remaining whole units, clears the date, and is ready for the next batch.
- A tooltip on the Expiration batch header explains the workflow without adding permanent instructional text to every row.

## Inventory navigation

- Inventory is now always expanded in the sidebar.
- The technical `Inventory Ledger` menu label is replaced with `Available Inventory`.
- The inventory page title and quantity formatting match the menu and warehouse language.
