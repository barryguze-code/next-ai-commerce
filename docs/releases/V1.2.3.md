# v1.2.3 — Movement history for sold-out items

## Changes
- A zero-stock catalogue result in Available Inventory now opens the same sliding inventory detail when its product title is clicked.
- The detail displays all historical movements for the item even when no current location or expiration batch remains.
- The selected-batch view is disabled when there is no current batch, while the full item ledger remains available.

## Deployment
No database migration or production data correction is included. Automated Java and browser tests run before production deployment.
