# v1.2.2 — Faster catalogue inventory actions

## Changes
- Marketplace SKUs, Account Catalogue, and Available Inventory share one Adjust Inventory action with location, expiration, quantity, reason, and explanation.
- Available Inventory search displays active catalogue items with zero stock so their first inventory position can be created immediately.
- Receiving provides a table-level Receive item action. Manual receipts require an explanation, are valued at zero cost, remain in the ledger, and refresh open-order reservations.
- Catalogue and mapping pickers show product pictures. Picture upload in inventory details is now a small overlay on the item picture.

## Performance
Catalogue lookup was improved without a database migration. Inventory positions are queried only for selected item IDs, mapped-product lookup is set-based, picture lookup is limited to the visible result set, and independent requests load concurrently. The local 20,000-item regression benchmark completed the image-aware picker lookup in 32 ms.

## Deployment
No database migration or production data correction is included. Automated Java and browser tests run before the verified package is sent to production. Existing deployment rollback safeguards remain enabled.
